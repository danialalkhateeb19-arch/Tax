# سنداتي — تطبيق شخصي لإدارة السندات

تطبيق ويب ثابت بالكامل (HTML/CSS/JS بدون أي أداة بناء)، يُخزّن بياناته في Firebase،
ويعمل كتطبيق PWA قابل للتثبيت على الهاتف. لا يوجد npm ولا build ولا سيرفر — كل ملف هنا
يعمل مباشرة بمجرد رفعه.

## الملفات

```
index.html          الصفحة الوحيدة
style.css           التصميم — كل الألوان متغيرات مركزية في أعلى الملف
app.js              كل منطق التطبيق (وحدة ES، بدون بناء)
manifest.json        بيانات تثبيت PWA
service-worker.js    التخزين المؤقت + العمل بدون إنترنت
firestore.rules      قواعد أمان Firestore (تُلصق يدوياً في Firebase Console)
icons/                أيقونات التطبيق (192، 512، صيغتا maskable، وأيقونة apple-touch-icon مخصصة لآيفون)
.nojekyll             ملف فارغ يمنع GitHub من معالجة الملفات عبر Jekyll — يضمن رفعها كما هي تماماً
```

## الإعداد (مرة واحدة فقط)

### 1. إنشاء مشروع Firebase

1. اذهب إلى [console.firebase.google.com](https://console.firebase.google.com) → **Add project**.
2. من القائمة الجانبية: **Build → Firestore Database → Create database** (اختر أي موقع قريب منك، وضع الإنتاج/Production mode).
3. من القائمة الجانبية: **Build → Authentication → Get started → Sign-in method → Anonymous → فعّلها (Enable)**.
   هذه الخطوة ضرورية — بدونها لن يستطيع التطبيق الاتصال بقاعدة البيانات.
4. من **Firestore Database → Rules**: امسح المحتوى الموجود، والصق محتوى ملف `firestore.rules` كاملاً، ثم اضغط **Publish**.

### 2. ربط ملفات التطبيق بمشروعك

1. من إعدادات المشروع (⚙️ Project settings) → أسفل الصفحة **Your apps** → اضغط أيقونة **</>" (Web)**.
2. سمِّ التطبيق أي اسم واضغط **Register app**. سيظهر لك كائن `firebaseConfig`.
3. افتح ملف `app.js` وابحث عن `firebaseConfig` في أعلى الملف، واستبدل القيم بالقيم الحقيقية من مشروعك.

### 3. الرفع على GitHub Pages

1. أنشئ مستودع (repository) جديد على GitHub، وارفع كل الملفات كما هي (بنفس الأسماء والمجلدات).
2. من إعدادات المستودع: **Settings → Pages → Source → Deploy from a branch → اختر `main` والمجلد `/root`** → Save.
3. بعد دقيقة أو دقيقتين سيظهر رابط التطبيق (شكله: `https://اسم_المستخدم.github.io/اسم_المستودع/`).

هذا كل شيء — لا يوجد `npm install`، ولا خطوة بناء، ولا سيرفر يجب تشغيله.

## تثبيت التطبيق على الهاتف

افتح الرابط من متصفح Chrome على الهاتف. سيظهر تلقائياً شريط سفلي بعنوان "ثبّت التطبيق"،
أو من قائمة المتصفح (⋮) اختر **"إضافة إلى الشاشة الرئيسية" / Add to Home Screen**.
بعد التثبيت يفتح التطبيق بواجهته الخاصة، بدون شريط عنوان المتصفح.

## تعديل الألوان

كل الألوان معرّفة كمتغيرات CSS في أعلى ملف `style.css` تحت `:root`. لتغيير أي لون،
عدّل قيمته هناك فقط — لا يوجد أي لون آخر مكتوب مباشرة في بقية الملف.

## طريقة حساب الربح

يستخدم التطبيق طريقة **متوسط التكلفة**: عند كل عملية شراء يُعاد حساب متوسط سعر الوحدة،
وعند كل عملية بيع يُحسب الربح المحقق كالفرق بين سعر البيع ومتوسط التكلفة عند تلك اللحظة.
"القيمة الحالية" للسندات المتبقية تعتمد على السعر الذي تُدخله يدوياً في بطاقة كل سند
(أو متوسط التكلفة كتقدير احتياطي إن لم تُدخل سعراً بعد) — لا يوجد اتصال بمصدر أسعار خارجي.
